    Generic weak-convergence tools #

    Extended continuous mapping, countability of positive-mass frontiers, Slutsky's theorem, and the approximation theorem for probability measures, on varying probability spaces where relevant.

    Reference: P. Billingsley, Convergence of Probability Measures, 2nd ed., Wiley, 1999, Theorems 2.7, 3.9 and 3.2. The labels C9–C11 in docstrings refer to the specification CLASSICAL_THEORY_INPUTS.md of this repository.

    Filter.Tendsto (fun (n : ℕ) => (μ n).map fun (ω : Ω n) => (X n ω, Y n ω)) Filter.atTop (nhds (P.map fun (x : S) => (x, c)))

    Slutsky on varying probability spaces (Billingsley 1999, Theorem 3.9): if X n converges in law and Y n converges in probability to a constant c, then the pair converges in law to the product of the limit law with the Dirac mass at c (C10(2)).

    Filter.Tendsto (fun (n : ℕ) => (μ n).map (Y n)) Filter.atTop (nhds ν)

    Approximation theorem (Billingsley 1999, Theorem 3.2), on varying probability spaces: if X u n ⇒ Z u as n → ∞, Z u ⇒ ν as u → ∞, and X u n approximates Y n uniformly in probability as u → ∞, then Y n ⇒ ν (C11(1)).
