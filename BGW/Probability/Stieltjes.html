    Finite-window operations on Stieltjes measures #

    Agreement, translation, and capping of Stieltjes functions on an initial interval give the corresponding identities and inequalities for their associated measures.

    source
    theorem BGW.Probability.stieltjes_restrict_Ioc_congr {F G : StieltjesFunction ℝ} {T : ℝ} (hT : 0 ≤ T) (he : ∀ x ∈ Set.Icc 0 T, ↑F x = ↑G x) :
    F.measure.restrict (Set.Ioc 0 T) = G.measure.restrict (Set.Ioc 0 T)

    Agreement of Stieltjes functions on a closed window gives agreement of their source measures.

    theorem BGW.Probability.stieltjes_min_restrict_le {F G : StieltjesFunction ℝ} {T c : ℝ} (hT : 0 ≤ T) (he : ∀ x ∈ Set.Icc 0 T, ↑G x = min (↑F x) c) :
