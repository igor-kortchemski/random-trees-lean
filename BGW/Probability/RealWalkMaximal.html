    Maximal inequalities for real iid walks #

    This file defines finite-horizon exceedance probabilities and proves Ottaviani's maximal inequality using first-exit events and fresh-start independence.

    Reference: P. Billingsley, Convergence of Probability Measures, 2nd ed., 1999, Theorem 9.7 (Ottaviani's inequality).

        theorem BGW.Probability.RealWalk.maximal_le_two_mul_tail (ν : MeasureTheory.ProbabilityMeasure ℝ) (m : ℕ) (r : ℝ) (hsafe : ∀ j ≤ m, 1 / 2 ≤ (↑(sumLaw ν j)).real {x : ℝ | |x| ≤ r}) :
        maxTail ν m (2 * r) ≤ 2 * (↑(sumLaw ν m)).real {x : ℝ | r < |x|}

        Ottaviani's maximal inequality for real iid sums (Node 6). If every partial sum S_j, j ≤ m, lies in [-r, r] with probability ≥ 1/2 (the "safe remainder" hypothesis, applied to the independent remainder S_m - S_k of length m - k ≤ m), then P(max_{k ≤ m} |S_k| > 2 r) ≤ 2 P(|S_m| > r).
