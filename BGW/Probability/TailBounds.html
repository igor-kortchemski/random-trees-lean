    Consequences of quantitative tail bounds #

    Geometric tail bounds give almost sure convergence, while exponential tail bounds give finite real moments with explicit Gamma-function estimates.

    theorem BGW.Probability.ae_tendsto_zero_of_geometric_tails {Ω : Type u_1} [MeasurableSpace Ω] (μ : MeasureTheory.Measure Ω) (D : ℕ → Ω → ℝ) (hD : ∀ᵐ (ω : Ω) ∂μ, ∀ (n : ℕ), 0 ≤ D n ω) (htail : ∀ (δ : ℝ), 0 < δ → ∃ (C : ℝ) (r : ℝ), 0 ≤ r ∧ r < 1 ∧ ∀ (n : ℕ), μ {ω : Ω | δ < D n ω} ≤ ENNReal.ofReal (C * r ^ n)) :
    ∀ᵐ (ω : Ω) ∂μ, Filter.Tendsto (fun (n : ℕ) => D n ω) Filter.atTop (nhds 0)
