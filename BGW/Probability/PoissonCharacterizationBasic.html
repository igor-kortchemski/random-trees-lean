            Prop

            Time-simple finite-rate random point measure: the structural hypotheses of the characterization.

            • measurable : Measurable ξ
            • atZero : ∀ᵐ (ω : Ω) ∂P, (ξ ω) ({0} ×ˢ Set.univ) = 0

              zero mass at label 0

            • counting : ∀ᵐ (ω : Ω) ∂P, ∃ (S : Set (NNReal × M)), S.Countable ∧ ξ ω = MeasureTheory.Measure.sum fun (p : ↑S) => MeasureTheory.Measure.dirac ↑p

              counting measure: a countable sum of unit point masses.

            • timeSimple : ∀ᵐ (ω : Ω) ∂P, ∀ (s : NNReal), (ξ ω) ({s} ×ˢ Set.univ) ≤ 1

              time-simplicity: almost surely at most one mark per time label.

            • stationary (a h : NNReal) : MeasureTheory.Measure.map (fun (ω : Ω) => windowShift a (a + h) (ξ ω)) P = MeasureTheory.Measure.map (fun (ω : Ω) => windowShift 0 h (ξ ω)) P

              stationarity of window restrictions
