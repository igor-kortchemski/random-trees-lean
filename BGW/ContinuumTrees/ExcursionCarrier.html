    The tagged excursion carrier #

    This module defines càdlàg excursions together with a positive lifetime tag. It proves that the carrier is standard Borel, constructs excursion cuts, and establishes space-time scaling and normalization with their measurability and group laws (J. Bertoin, Lévy Processes, Cambridge University Press, 1996, Chapter IV; L. Chaumont, Excursion normalisée, méandre et pont pour les processus de Lévy stables, Bull. Sci. Math. 121 (1997), 377–403).

                    def BGW.StableTrees.cutValid (g d : NNReal) (f : Skorokhod.DLoc) :
                    Prop

                    Cut-validity: between times g < d, f d = f g and f ≥ f g on [g, d].

                    A valid cut uses the post-jump value f g as the base level (the cut path is f(g + ·) - f g), so excursionCut never represents an excursion that starts with a jump out of the infimum; this is consistent with IsExcursionInterval (in BGW.StableTrees.ReflectedRestart), which requires R g = 0.
