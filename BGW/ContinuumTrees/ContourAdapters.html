    Adapters for paper contour conventions #

    The library contour uses duration 2(ζ - 1), while the paper uses duration 2ζ and sets the contour to zero after its tree has been explored. This module proves the time-change and law-transfer bounds between these conventions, measurability for random finite trees, and the divisor estimates from Remark 5.10.

    The paper convention is that of I. Kortchemski, Invariance principles for Galton–Watson trees conditioned on the number of leaves (arXiv:1110.2163), with the contour C_{2ζ s}; see also J.-F. Le Gall, Random trees and applications (2005), §1. These adapters serve item C38 of CLASSICAL_THEORY_INPUTS.md.

        the deterministic divisor of Remark 5.10 #

        N n is the (deterministic) number of leaves, B n the stable normalizer, μ₀ > 0 the offspring mean parameter of the paper, θ > 0 the stability index; b n = N n / (μ₀^(1-1/θ) B n).
