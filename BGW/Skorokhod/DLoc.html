    Compatible families for the local càdlàg path space #

    This module extends the basic DLoc API with the measurable equivalence between local càdlàg paths and compatible families of restrictions to integer horizons. It also proves that finite laws on DLoc are determined by these restrictions.

    The construction uses PathLawFamily; the law-independent carrier, filtrations, and passage times are provided by DLocBasic.
