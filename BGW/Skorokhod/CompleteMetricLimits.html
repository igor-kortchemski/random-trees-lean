    Limits of time changes with bounded logarithmic slope #

    A uniform slope bound prevents degeneration of a pointwise limit: its lower secant bound remains strictly positive. Logarithmic slope bounds pass to limits of time changes.

    source
    theorem BGW.Skorokhod.TimeChange.secant_bounds_of_logSlope_le {T : ℝ} (σ : TimeChange T) {r : ℝ} (hr : 0 ≤ r) (hσ : σ.logSlope ≤ ENNReal.ofReal r) {s t : ↑(Set.Icc 0 T)} (hst : s < t) :
    Real.exp (-r) * (↑t - ↑s) ≤ ↑(σ t) - ↑(σ s) ∧ ↑(σ t) - ↑(σ s) ≤ Real.exp r * (↑t - ↑s)

    A logarithmic slope bound is equivalent to exponential two-sided secant bounds.
