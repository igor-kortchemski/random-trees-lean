    Deterministic exit partitions #

    Restart exit times give a finite partition with small oscillation on its half-open blocks. When successive exits of the walk are far apart and the initial and terminal windows are good, Billingsley's modulus w' of the rescaled step path t ↦ S_{⌊nt⌋} / b is at most 4ε (cadlagModulus_realStepPath_le). This is the deterministic step of the tightness argument for walks in a stable domain of attraction (Billingsley 1999, §12–13), following the campaign's audited plan (node 8).

                      theorem BGW.Skorokhod.cadlagModulus_realStepPath_le {T : ℝ} {n : ℕ} {b ε δ : ℝ} {ω : ℕ → ℝ} (hT : 0 < T) (hn : 1 ≤ n) (hb : 0 < b) (hε : 0 < ε) (hδ : 0 < δ) (hδT : 4 * δ < T) (hsep : ¬Probability.RealWalk.closeExit ⌊↑n * T⌋₊ (ε * b) ⌈2 * ↑n * δ + 2⌉₊ ω) (hinit : ¬Probability.RealWalk.initialBad T n b ε δ ω) (hterm : ¬Probability.RealWalk.terminalBad T n b ε δ ω) :
                      cadlagModulus (realStepPath T n b ω) δ ≤ 4 * ε

                      Node 8, deterministic bound. Hypotheses (i) no close consecutive exits at scale ε b, with index gap l = ⌈2 n δ + 2⌉₊ (so that consecutive cuts are more than 2δ apart in time, the +2 absorbing the floors), (ii) no big initial move, (iii) no big terminal move. The exits live in the walk of length M = ⌊n T⌋₊. Conclusion: w'(δ) ≤ 4 ε for Billingsley's modulus (half-open blocks, all steps > δ, δ < T).
