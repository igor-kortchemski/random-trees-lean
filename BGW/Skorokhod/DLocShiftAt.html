    Random-time shifts of local càdlàg paths #

    This file defines the centered shift of a local càdlàg path at an extended nonnegative random time and records its basic measurability properties, including measurability of the stopped coordinates (O. Kallenberg, Foundations of Modern Probability, 2nd ed., Springer, 2002, Chapter 7).

    source
    noncomputable def BGW.Skorokhod.DLoc.shiftAt (τ : DLoc → ENNReal) (f : DLoc) :
    DLoc

    Post-τ centered shift. shiftAt τ f = (u ↦ f (τ f + u) - f (τ f)) when τ f < ⊤; junk value shift 0 f when τ f = ⊤.
