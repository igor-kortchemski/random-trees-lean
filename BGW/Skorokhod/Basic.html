    Càdlàg paths with Billingsley's J1 metric #

    This file defines the space of càdlàg paths on a compact real interval and proves that Billingsley's J1 distance is a metric when the state space is metric.

    Horizon conventions: no sign condition on T is imposed. For T < 0 the time domain is empty, D T E is a singleton and every displayed supremum and distance is 0 (Mathlib's convention for empty real suprema). For T = 0, evaluation at 0 identifies D 0 E isometrically with E. The ordinary J1 metric is not complete; Polishness needs Billingsley's equivalent metric d° and is not provided here.

    References: P. Billingsley, Convergence of Probability Measures, 2nd ed., 1999, §12; S. N. Ethier and T. G. Kurtz, Markov Processes, 1986, ch. 3 (general metric state spaces).
