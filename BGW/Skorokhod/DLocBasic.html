    Basic API for the local càdlàg path space #

    The space DLoc consists of real càdlàg paths on nonnegative time. It carries the σ-algebra generated by evaluations, together with restriction, shifting, natural filtrations, and strict passage times. This module is independent of path-law constructions and Kolmogorov extension.

    References #

    • P. Billingsley, Convergence of Probability Measures, 2nd ed., Wiley, 1999, Section 16.
    • D. Revuz and M. Yor, Continuous Martingales and Brownian Motion, 3rd ed., Springer, 1999, Chapter I, Section 4.
