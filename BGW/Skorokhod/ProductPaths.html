    Pairing a càdlàg path with a continuous path #

    The pair of a càdlàg real path and a continuous real path is a càdlàg path with values in ℝ × ℝ. The pairing map is jointly continuous for the Skorokhod J1 topology and the uniform topology on continuous paths. The same time changes control both coordinates; in the continuous coordinate one also uses uniform convergence and uniform continuity of the limiting path.

    Reference: P. Billingsley, Convergence of Probability Measures, 2nd ed., Wiley, 1999, Section 12.
