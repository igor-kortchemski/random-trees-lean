    Reversed clocks and ancestral windows #

    Measurable compact occupation functions transport uniform convergence to reversed prefixes. At every ancestral time of a fixed horizon, contact restart identifies the earlier height as the difference of two values of that clock. Endpoint jumps are retained explicitly.

    ∀ᵐ (f : Skorokhod.DLoc) ∂↑(stableLocalLaw θ), (∀ u ≤ T, Filter.Tendsto (fun (k : ℕ) => supOccupation (supEps θ k) (reversedAt T f) u) Filter.atTop (nhds (supLocalTime θ (reversedAt T f) u))) ∧ (Continuous fun (u : ↑(Set.Iic T)) => supLocalTime θ (reversedAt T f) ↑u) ∧ (Monotone fun (u : ↑(Set.Iic T)) => supLocalTime θ (reversedAt T f) ↑u) ∧ supLocalTime θ (reversedAt T f) 0 = 0

    ∀ᵐ (f : Skorokhod.DLoc) ∂↑(stableLocalLaw θ), ∀ s ≤ t, Function.leftLim (↑f) s ≤ futureInf f t s → Filter.Tendsto (fun (k : ℕ) => heightApprox (supEps θ k) f s) Filter.atTop (nhds (height θ f s)) ∧ 0 ≤ height θ f s ∧ heightRaw θ f s = ENNReal.ofReal (height θ f s) ∧ height θ f s = supLocalTime θ (reversedAt t f) t - supLocalTime θ (reversedAt t f) (t - s)

    For a fixed horizon, all its ancestral times have finite identified height on one event.
