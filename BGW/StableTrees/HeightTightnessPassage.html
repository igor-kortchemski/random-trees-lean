    Small-time estimates for the first height upcrossing #

    Forest ladder times have the canonical walk passage law. Passage convergence keeps positive tree levels away from time zero. Combining this with the survival union bound and then choosing a small tree level gives the eventual small-time bound for the first height upcrossing.

    source
    theorem BGW.StableTrees.HeightTightness.map_scaled_ladderTime (μ : PMF ℕ) (hc : IsCritical μ) (hne : μ 1 ≠ 1) (l n : ℕ) :
    MeasureTheory.Measure.map (fun (ω : ℕ → ℕ) => ↑(DiscreteForest.ladderTime ω l) / ↑n) ↑(DiscreteForest.offspringSeqLaw μ) = walkPassageLaw μ l n

    The rescaled ladder time of the offspring forest has the canonical walk passage law.

    At a positive limiting tree level, the scaled ladder times stay away from zero in probability, eventually in the scaling index.

    The scaled first height upcrossing has uniformly vanishing mass near time zero, in the eventual form needed for the renewal argument.
