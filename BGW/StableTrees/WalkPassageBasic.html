    First passage of the canonical offspring walk #

    The weak downward hitting time of the canonical real walk is identified with the Łukasiewicz code of a finite forest. Criticality makes the hitting time almost surely finite. The step-path formulation is deterministic and is the input to the functional stable limit theorem (J. H. B. Kemperman, The Passage Problem for a Stationary Markov Chain, University of Chicago Press, 1961; J. Pitman, Combinatorial Stochastic Processes, Springer, 2006, Section 6.1).

        theorem BGW.StableTrees.walkHitTime_le_iff_iInf_stepPath_le {ℓ n : ℕ} {t b : ℝ} (ht : 0 ≤ t) (hb : 0 < b) (w : ℕ → ℝ) :
        walkHitTime ℓ w ≤ ↑⌊↑n * t⌋₊ ↔ ⨅ (s : ↑(Set.Icc 0 t)), (Skorokhod.realStepPath t n b w) s ≤ -↑ℓ / b

        Weak hit versus running minimum of the step path (deterministic, no limit): for b > 0, walkHitTime ℓ ≤ ⌊n t⌋ ↔ inf_{s ≤ t} realStepPath ≤ -ℓ/b. The infimum over [0, t] of the step path is a minimum over j ≤ ⌊n t⌋, so the WEAK inequality ≤ -ℓ/b is exact.
