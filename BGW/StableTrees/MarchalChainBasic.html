    Basic finite labelled trees for the Marchal chain #

    This module defines labelled trees, their quotient by label-preserving graph isomorphism, the initial edge, and the weight invariant used in Marchal's exact law.

    source
    structure BGW.StableTrees.Marchal.LTree (n : ℕ) :
    Type

    Finite leaf-labelled trees with leaves exactly A_0, …, A_n and no degree-two vertex.

    • m : ℕ

      Number of vertices.

    • G : SimpleGraph (Fin self.m)

      The tree.

    • tree : self.G.IsTree
    • labels : Fin (n + 1) ↪ Fin self.m

      Leaf A_i is the vertex labels i.

    • leaf (v : Fin self.m) : self.G.degree v = 1 ↔ v ∈ Set.range ⇑self.labels
    • branch (v : Fin self.m) : self.G.degree v ≠ 1 → 3 ≤ self.G.degree v
