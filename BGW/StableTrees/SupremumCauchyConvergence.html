    Almost sure compact convergence of the fast occupation sequence #

    Chebyshev and Borel–Cantelli give summable adjacent errors on growing integer horizons. Completeness of continuous functions on each compact then identifies the raw real limsup.

    References #

    • [J. Bertoin, Lévy Processes, Cambridge University Press, 1996, Chapter IV]
    source
    theorem BGW.StableTrees.abs_sub_supOccupation_le_compactError {ε η : ℝ} (hε : 0 < ε) (hη : 0 < η) (T : NNReal) (f : Skorokhod.DLoc) (t : ↑(Set.Iic T)) :
    |supOccupation ε f ↑t - supOccupation η f ↑t| ≤ compactError ε η T f

    Each pointwise error is bounded by its compact supremum.
