    Simultaneous ancestral height identification #

    A countable intersection over rational horizons identifies every ancestral time. The Stieltjes source is carried by strict ancestors and upward-jump endpoints, so this event also gives the simultaneous measure-level bridge without Lebesgue disintegration.

    theorem BGW.StableTrees.exists_rat_horizon_of_ancestor (f : Skorokhod.DLoc) {t s : NNReal} (ha : s < t ∧ Function.leftLim (↑f) s ≤ futureInf f t s ∨ s = t ∧ Function.leftLim (↑f) t < ↑f t) :
    ∃ (q : ℚ), 0 < ↑q ∧ s ≤ (↑q).toNNReal ∧ Function.leftLim (↑f) s ≤ futureInf f (↑q).toNNReal s

    ∀ᵐ (f : Skorokhod.DLoc) ∂↑(stableLocalLaw θ), ∀ (t : NNReal), ∀ᵐ (s : ℝ) ∂(explorationStieltjes f t).measure.restrict (Set.Ioc 0 ↑t), 0 ≤ height θ f s.toNNReal ∧ heightRaw θ f s.toNNReal = ENNReal.ofReal (height θ f s.toNNReal)

    Measure-level bridge (endpoint atoms retained): a.s., for every t, the random Stieltjes measure of x ↦ I^x_t on (0,t] is carried by times where H is finite, nonnegative and equal to the raw height. Must be proved by Stieltjes ancestral concentration, NOT by Fubini against Lebesgue measure from ae_heightRaw_eq.
