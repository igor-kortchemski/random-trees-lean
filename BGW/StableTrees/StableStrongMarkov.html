    Strong Markov property of the stable process on local càdlàg paths #

    This module proves the strong Markov property of stableLocalLaw at stopping times of the right-continuous natural filtration. Countably valued upper grid approximations reduce the argument to deterministic times, and càdlàg sample paths give convergence of finite-dimensional future laws (J. Bertoin, Lévy Processes, Cambridge University Press, 1996, Chapter I, Proposition 6; O. Kallenberg, Foundations of Modern Probability, 2nd ed., Springer, 2002, Theorem 13.11).

    theorem BGW.StableTrees.integral_shiftAt_mul_past {θ : ℝ} (hθ : 1 < θ ∧ θ ≤ 2) {τ : Skorokhod.DLoc → ENNReal} (hτ : MeasureTheory.IsStoppingTime Skorokhod.DLoc.filtration τ) {A : Set Skorokhod.DLoc} (hA : MeasurableSet A) (hAτ : A ⊆ {f : Skorokhod.DLoc | τ f < ⊤}) {F : Skorokhod.DLoc → ℝ} (hF : Measurable F) (hFb : ∃ (C : ℝ), ∀ (x : Skorokhod.DLoc), |F x| ≤ C) :
    ∫ (f : Skorokhod.DLoc) in A, F (Skorokhod.DLoc.shiftAt τ f) ∂↑(stableLocalLaw θ) = (↑(stableLocalLaw θ)).real A * ∫ (f : Skorokhod.DLoc), F f ∂↑(stableLocalLaw θ)

    Strong Markov property, integral form. For A in the stopped σ-algebra of τ with A ⊆ {τ < ⊤} and bounded Borel F on DLoc, ∫_A F(shiftAt τ f) dP = P(A) · ∫ F dP. (A = ∅ and τ ≡ 0 allowed.)

    theorem BGW.StableTrees.measure_inter_preimage_shiftAt {θ : ℝ} (hθ : 1 < θ ∧ θ ≤ 2) {τ : Skorokhod.DLoc → ENNReal} (hτ : MeasureTheory.IsStoppingTime Skorokhod.DLoc.filtration τ) {A : Set Skorokhod.DLoc} (hA : MeasurableSet A) (hAτ : A ⊆ {f : Skorokhod.DLoc | τ f < ⊤}) {B : Set Skorokhod.DLoc} (hB : MeasurableSet B) :
    ↑(stableLocalLaw θ) (A ∩ Skorokhod.DLoc.shiftAt τ ⁻¹' B) = ↑(stableLocalLaw θ) A * ↑(stableLocalLaw θ) B

    Independence form. Under the conditional probability given {τ < ⊤} (when that event has positive probability), the stopped σ-algebra restricted to the event is independent of the post-τ path. Stated with the restricted (non-normalised) measure, so that the null case is vacuous-true and no division is needed: for stopped events A ⊆ {τ < ⊤} and Borel B, P(A ∩ shiftAt τ ⁻¹ B) = P(A) · P(B).

    Law of the post-τ path. Conditionally on {τ < ⊤} (i.e. under the restriction of P to it), shiftAt τ has the law stableLocalLaw θ, scaled by the mass of {τ < ⊤}.
