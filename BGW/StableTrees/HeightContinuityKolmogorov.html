    Kolmogorov regularity of stable heights #

    The moment estimate supplies the vendored Kolmogorov condition on nonnegative time. A continuous modification agrees at every rational time on a common event, identifying it with the deterministic universal-sequence reconstruction.

    source
    theorem BGW.StableTrees.exists_height_isKolmogorovProcess {θ : ℝ} (hθ : 1 < θ ∧ θ ≤ 2) {p : ℝ} (hp : 1 ≤ p) :
    ∃ (M : NNReal), ProbabilityTheory.IsKolmogorovProcess (fun (t : NNReal) (f : Skorokhod.DLoc) => height θ f t) (↑(stableLocalLaw θ)) p (p * (1 - 1 / θ)) M

    The increment moment estimate gives the Kolmogorov condition with dimension one.

    source
    theorem BGW.StableTrees.exists_height_continuous_modification {θ : ℝ} (hθ : 1 < θ ∧ θ ≤ 2) :
    ∃ (Y : NNReal → Skorokhod.DLoc → ℝ), (∀ (f : Skorokhod.DLoc), Continuous fun (t : NNReal) => Y t f) ∧ ∀ (t : NNReal), ∀ᵐ (f : Skorokhod.DLoc) ∂↑(stableLocalLaw θ), Y t f = height θ f t

    A sufficiently high moment gives a continuous modification on nonnegative time.
