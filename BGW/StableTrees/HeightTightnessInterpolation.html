    Integer grid enclosures and linear interpolation #

    Long regeneration gaps control short integer rises. Close enclosing grid values then bound all integer heights between them. Convex interpolation preserves the same enclosure, including large downward steps.

    source

    ∃ j < L, r j ≤ s ∧ s < r (j + 1)
