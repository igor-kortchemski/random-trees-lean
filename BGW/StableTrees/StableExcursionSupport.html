    Excursion support of the reflected stable process #

    The positive set is exactly the union of the passage-jump intervals, simultaneously on one full-probability event. Their starts are continuous, their endpoints identify every excursion candidate, and their complement has zero Lebesgue measure (J. Bertoin, Lévy Processes, Cambridge University Press, 1996, Chapter VII).

    theorem BGW.StableTrees.ae_jump_window_inf {θ : ℝ} (hθ : 1 < θ ∧ θ ≤ 2) :
    ∀ᵐ (f : Skorokhod.DLoc) ∂↑(stableLocalLaw θ), ∀ x ∈ passageJumpSet f, 0 < passageTimeMinus x f ∧ Function.leftLim (↑f) (passageTimeMinus x f) = -↑x ∧ ∀ (r q : ℚ≥0), ↑r < passageTimeMinus x f → passageTimeMinus x f < ↑q → ↑q < passageTime x f → ⨅ (u : ↑(Set.Icc ↑r ↑q)), ↑f ↑u = -↑x

    Window minima from plateau inequalities (no uniqueness needed). Simultaneously for every jump level x: X has left limit -x at T_{x-}, T_{x-} > 0, and over every rational window r < T_{x-} < q < T_x the infimum of X is -x.

    theorem BGW.StableTrees.ae_pos_set_eq_iUnion_jump_intervals {θ : ℝ} (hθ : 1 < θ ∧ θ ≤ 2) :
    ∀ᵐ (f : Skorokhod.DLoc) ∂↑(stableLocalLaw θ), {t : NNReal | 0 < ↑(reflectedFrom 0 f) t} = ⋃ x ∈ passageJumpSet f, Set.Ioo (passageTimeMinus x f) (passageTime x f)

    The reflected process is positive exactly on the union of the excursion intervals (a.s., an equality of sets, not merely up to a null set): {R > 0} = ⋃_{x ∈ jump levels} (T_{x-}, T_x); equivalently R vanishes off the union, and the zero set is the Lebesgue-null complement of ae_zeroSet_volume_zero.

    ∀ᵐ (f : Skorokhod.DLoc) ∂↑(stableLocalLaw θ), MeasureTheory.volume (NNReal.toReal '' (⋃ x ∈ passageJumpSet f, Set.Ioo (passageTimeMinus x f) (passageTime x f))ᶜ) = 0
