    Real scalar stable attraction #

    This module packages weak attraction of real iid sums, proves the convergence-of-types theorem for arbitrary eventually positive normalizers, and connects the real formulation to the existing integer walk and offspring stable-domain predicates.

    References: W. Feller, An Introduction to Probability Theory and Its Applications, vol. II, ch. XVII; N. H. Bingham, C. M. Goldie and J. L. Teugels, Regular Variation (1987), §1.5 (Potter bounds).

    Real scalar attraction (audit correction 1): B n > 0 only eventually; no monotonicity, no centering, and no moment assumption.

    • index_mem : 1 < θ ∧ θ ≤ 2
    • pos : ∀ᶠ (n : ℕ) in Filter.atTop, 0 < B n
    • converges : Filter.Tendsto (fun (n : ℕ) => Probability.RealWalk.scaledSumLaw ν B n) Filter.atTop (nhds (stableLaw θ))
