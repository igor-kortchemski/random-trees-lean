    The killed-gap Green kernel #

    The gap walk started at x > 0 is killed when the original increment walk first reaches x. Prepending x zero offspring values embeds it in a first weak cycle. Duality then gives a finite Green kernel without any offspring second moment. The bound here is geometric in x; it is not the scale-uniform renewal estimate.
