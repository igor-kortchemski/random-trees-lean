    Measurability of the first long excursion #

    Rational label windows detect the first long label. Their countable infimum supplies a measurable version of the raw infimum selector on the almost-sure selection event.

    Reference: J. Bertoin, Lévy Processes, Cambridge University Press, 1996, Chapter IV.

    source
    theorem BGW.StableTrees.longCount_eq_zero_iff {f : Skorokhod.DLoc} (hc : (passageJumpSet f).Countable) (hs : ∀ x ∈ passageJumpSet f, (jumpExcursion x f).lifetime = passageTime x f - passageTimeMinus x f) (t : NNReal) :
    (excursionPointMeasure f) (Set.Ioc 0 t ×ˢ {e : Excursion | 1 < e.lifetime}) = 0 ↔ ∀ x ∈ longLabelSet f, t < x

    On paths with valid excursion tags, a void long-mark window is equivalent to having all long labels strictly beyond the end of the window.
