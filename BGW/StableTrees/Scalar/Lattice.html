    The span of the offspring law and lattice Fourier inversion #

    Source lines 855–883 ("Periodicity"). The span of μ is d = gcd {i - j : μ_i μ_j > 0} (BGW.StableTrees.Scalar.latticeSpan, defined literally as the greatest common divisor of the differences). For critical μ with μ_1 ≠ 1 we have μ_0 > 0, so every support point is a multiple of d, and X = K - 1 ∈ -1 + dℤ; hence S_n ∈ -n + dℤ (this is the paper's lattice nb + dℤ with the support point b = -1).

    • BGW.StableTrees.Scalar.stepCF_add_period: φ(θ + 2π/d) = e^{-2πi/d} φ(θ);
    • BGW.StableTrees.Scalar.norm_stepCF_lt_one: |φ(θ)| < 1 for 0 < |θ| ≤ π/d (via Bezout: d is an integer combination of support differences);
    • BGW.StableTrees.Scalar.walkLaw_real_singleton_eq_zero: P(S_n = k) = 0 unless d ∣ k + n;
    • BGW.StableTrees.Scalar.walkLaw_real_singleton_lattice: for d ∣ k + n, P(S_n = k) = (d/2π) ∫_{-π/d}^{π/d} φ(θ)^n e^{-ikθ} dθ.
