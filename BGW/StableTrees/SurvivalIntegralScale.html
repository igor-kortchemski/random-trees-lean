    Scaling the reciprocal-defect integral #

    A Potter bound extended to the whole unit interval gives an integrable majorant for the rescaled reciprocal defect.

    source
    theorem BGW.StableTrees.Survival.exists_offspringDefect_potter_unit {μ : PMF ℕ} {θ : ℝ} {B : ℕ → ℝ} (h : StableDomain μ θ B) {p : ℝ} (hp0 : 0 ≤ p) (hp : p < θ) :
    ∃ (v₀ : ℝ) (C : ℝ), 0 < v₀ ∧ v₀ ≤ 1 ∧ 0 < C ∧ ∀ (u v : ℝ), 0 < u → u ≤ v₀ → u ≤ v → v ≤ 1 → C * (v / u) ^ p * offspringDefect μ u ≤ offspringDefect μ v
