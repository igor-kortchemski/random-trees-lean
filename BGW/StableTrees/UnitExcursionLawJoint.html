    theorem BGW.StableTrees.shapeLifetime_map_of_scaling {θ : ℝ} (hθ : 1 < θ ∧ θ ≤ 2) (ν : MeasureTheory.Measure Excursion) (hν : ∀ (c : ↑(Set.Ioi 0)), MeasureTheory.Measure.map (excursionScale θ c) ν = ENNReal.ofReal (↑c ^ (1 / θ)) • ν) (hfin : ν {e : Excursion | 1 < ↑e.lifetime} < ⊤) :
    MeasureTheory.Measure.map (shapeLifetime θ) ν = ENNReal.ofReal (Real.Gamma (1 - 1 / θ)) • (lifetimeLaw θ).prod (MeasureTheory.Measure.map (normalizeExc θ) (ν.restrict {e : Excursion | 1 < ↑e.lifetime}))

    Uniqueness of scaling-consistent families: a measure ν with (S_c)_* ν = c^{1/θ} • ν for all c > 0 and ν {ζ > 1} < ∞ is determined by its unit shape measure (normalizeExc)_* (ν ↾ {ζ > 1}): (ζ, normalizeExc)_* ν = Γ(1-1/θ) • lifetimeLaw ⊗ (normalizeExc)_* (ν ↾ {ζ > 1}).
