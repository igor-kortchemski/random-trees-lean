    Borel reconstruction from rational heights #

    The rational evaluation map is an injective Borel map from the Polish space of continuous functions. Its range is Borel and its inverse is measurable. This controls the choice in both height reconstructions, for every parameter and every input path.

    Measurable fun (f : Skorokhod.DLoc) => { toFun := heightLoc θ f, continuous_toFun := ⋯ }

    The bundled continuous height is measurable, including the zero branch.
