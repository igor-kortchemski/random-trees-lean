    Height of the straddling excursion #

    The continuous height of the normalized excursion straddling a fixed positive time is the normalized host height. The joint law of the normalized path and height is excLaw, and it is independent of the age and lifetime of the straddling excursion.

    C(↑(Set.Icc 0 1), ℝ)

    Normalized host height of the straddling excursion (C25, height part): the continuous function s ↦ ζ_t^{1/θ-1} H_{g_t + ζ_t s} on [0,1], with H = heightLoc θ f the continuous height of the host path.
