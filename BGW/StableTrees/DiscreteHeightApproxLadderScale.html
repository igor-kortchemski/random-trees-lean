    The weak ladder-height Laplace scale #

    At parameter 1/B_n, the first-height transform has defect asymptotic to B_n/n. This gives an exponential tail for the number of weak epochs below a bounded height.

    source
    theorem BGW.StableTrees.DiscreteHeightApprox.tendsto_scaled_ladderPGF_defect {μ : PMF ℕ} {θ : ℝ} {B : ℕ → ℝ} (h : StableDomain μ θ B) :
    Filter.Tendsto (fun (n : ℕ) => ↑n / B n * (1 - (weakLadderPGF μ (ENNReal.ofReal (Real.exp (-1 / B n)))).toReal)) Filter.atTop (nhds 1)
