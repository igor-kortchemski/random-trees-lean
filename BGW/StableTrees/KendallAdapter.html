    Kendall adapter and Gamma analytic interface #

    The time-first Kendall kernel is adapted from the passage-time density theorem. Its survival kernel is identified with the passage-time tail, and is proved finite, positive, measurable, and jointly continuous on its natural domain. The Gamma factor inherits the corresponding regularity API.

    Main declarations: qKernel (q_s(x) = (x/s) p_s(-x)), passageLaw_eq_qKernel, sizeTailKernelENN and sizeTailKernelENN_eq_passageLaw (G_r(x) = P(T_x > r)), the integrable dominator qKernel_le_of_ge, continuity and measurability lemmas, and gammaA with gammaA_mul_sizeTail.

    References #

    • D. G. Kendall, Some problems in the theory of dams, J. Roy. Statist. Soc. Ser. B 19 (1957), 207–212.
    • J. Bertoin, Lévy Processes, Cambridge University Press, 1996, Chapter VII (Corollary VII.3).

            Continuity and local bounds #

            source
            theorem BGW.StableTrees.qKernel_le_of_ge {θ : ℝ} (hθ : 1 < θ ∧ θ ≤ 2) {r : ℝ} (hr : 0 < r) (X : ℝ) :
            ∃ (C : ℝ), ∀ (s : ℝ), r ≤ s → ∀ (x : ℝ), 0 ≤ x → x ≤ X → qKernel θ s x ≤ C * x * s ^ (-1 - 1 / θ)

            Local integrable dominator (from Scalar.exists_stableDensity_le, q_s(x) = (x/s) p_s(-x) and p_s ≤ M s^{-1/θ}): for r > 0 and X ≥ 0 there is C (depending on θ, r, X) with q_s(x) ≤ C x s^{-1-1/θ} for all s ≥ r, 0 ≤ x ≤ X. The right side is integrable on s ≥ r (exponent -1-1/θ < -1), uniformly in x ≤ X.
