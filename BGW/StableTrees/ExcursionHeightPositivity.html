    Simultaneous interior positivity #

    Positivity on every compact interior rational window is a Borel event in the compact-open continuous-map space. Compensation transfers host positivity to the excursion measure; the shape/lifetime law and fixed-scale unit scaling transfer it to the unit law.

    source
    theorem BGW.StableTrees.measurableSet_excursionHeight_pos (θ : ℝ) :
    MeasurableSet {e : Excursion | ∀ (t : NNReal), 0 < t → t < e.lifetime → 0 < (excursionHeight θ e) t}

    Strict positivity at every interior age is a Borel event of the excursion.
