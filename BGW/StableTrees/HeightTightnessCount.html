    Uniform tightness of the regenerated crossing count #

    A uniformly positive chance of a macroscopic gap contracts the Laplace transform below one. The exponential crossing-count bound then controls the number of crossings before any fixed scaled horizon.

    ∫ (ω : ℕ → ℕ), Real.exp (-↑(heightUpcrossingStop q ω).toNat / ↑n) ∂↑(DiscreteForest.offspringSeqLaw μ) ≤ Real.exp (-↑m / ↑n) + (1 - Real.exp (-↑m / ↑n)) * (↑(DiscreteForest.offspringSeqLaw μ)).real {ω : ℕ → ℕ | (heightUpcrossingStop q ω).toNat ≤ m}
