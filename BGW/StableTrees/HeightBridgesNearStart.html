    First moments of the height occupation near the excursion start #

    Translation of Lebesgue measure identifies the approximation on the later window, and the difference is exactly the occupation before the split age. Tonelli converts the error from deleting an initial age window into the integral of the small-depth probabilities. No pathwise sequence identification is required.

    source
    theorem BGW.StableTrees.heightApprox_sub_shift_eq (ε : ℝ) (f : Skorokhod.DLoc) (t a : NNReal) (hat : a ≤ t) :
    heightApprox ε f t - heightApprox ε (Skorokhod.DLoc.shift a f) (t - a) = ε⁻¹ * (MeasureTheory.volume {s : ℝ | 0 ≤ s ∧ s < ↑a ∧ ↑f s.toNNReal < futureInf f t s.toNNReal + ε}).toReal

    Splitting the approximation leaves precisely its occupation before the split age.
