    The global contour and height comparison #

    First-visit times recover all DFS heights from the contour. Compact sets of contours control their suprema and oscillations, making the first-visit clock displacement vanish.

    theorem BGW.StableTrees.ExactContour.eventually_globalError_le_of_compact {μ : PMF ℕ} {θ : ℝ} {B : ℕ → ℝ} (h : StableDomain μ θ B) (K : Set C(↑unitInterval, ℝ)) (hK : IsCompact K) {ε : ℝ} (hε : 0 < ε) :
    ∀ᶠ (n : ℕ) in Filter.atTop, ∀ (t : PlaneTree), t.size = n → treeContourPath B n 1 t.toLocallyFinite ∈ K → contourHeightError B n 1 t.toLocallyFinite ≤ ε

    On compact sets of normalized contours, the global height/contour error vanishes.
