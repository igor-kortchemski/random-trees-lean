    Markov property of the stable process on local càdlàg paths #

    This module establishes the simple Markov property of the local stable process for its natural right-continuous filtration, together with its integral and conditional-expectation forms, the germ zero-one law, and the exponential martingale (J. Bertoin, Lévy Processes, Cambridge University Press, 1996, Chapter I, Proposition 6 and Chapter VIII; R. M. Blumenthal, An extended Markov property, Trans. Amer. Math. Soc. 85 (1957), for the zero-one law).

    theorem BGW.StableTrees.integral_shiftIncrement_mul_past_stableProcessLaw {θ T s : ℝ} (hθ : 1 < θ ∧ θ ≤ 2) (hT : 0 < T) (hs : 0 ≤ s) (hsT : s ≤ T) (P : MeasureTheory.Measure (Skorokhod.D T ℝ)) (hP : P = ↑(stableProcessLaw θ T)) (Q : MeasureTheory.Measure (Skorokhod.D (T - s) ℝ)) (hQ : Q = ↑(stableProcessLaw θ (T - s))) {m : MeasurableSpace (Skorokhod.D T ℝ)} (hm : m ≤ MeasurableSpace.comap (Skorokhod.restrict hsT) inferInstance) {A : Set (Skorokhod.D T ℝ)} (hA : MeasurableSet A) {F : Skorokhod.D (T - s) ℝ → ℝ} (hF : Measurable F) (hFb : ∃ (C : ℝ), ∀ (x : Skorokhod.D (T - s) ℝ), |F x| ≤ C) :
    ∫ (f : Skorokhod.D T ℝ) in A, F (Skorokhod.shiftIncrement hs hsT f) ∂P = P.real A * ∫ (g : Skorokhod.D (T - s) ℝ), F g ∂Q

    Bounded-test form. For every sub-σ-algebra m ≤ comap (restrict hsT) of the natural past, A m-measurable and bounded Borel F on the future path space, ∫_A F(future) dP = P(A) · ∫ F d(law of the future). The measures P, Q are bound before m (with equations to the stable laws) so that they carry the Borel σ-algebra, not m, which would otherwise become the local MeasurableSpace (D T ℝ) instance.
