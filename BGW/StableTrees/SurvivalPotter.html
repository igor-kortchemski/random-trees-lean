    Bounds for the offspring defect near zero #

    Sequential regular variation gives a right-hand filter limit. A fixed doubling estimate then gives a lower Potter bound, by iteration on dyadic scales.

    source
    theorem BGW.StableTrees.Survival.tendsto_offspringDefect_ratio_nhdsGT {μ : PMF ℕ} {θ : ℝ} {B : ℕ → ℝ} (h : StableDomain μ θ B) {c : ℝ} (hc : 0 < c) :
    Filter.Tendsto (fun (u : ℝ) => offspringDefect μ (c * u) / offspringDefect μ u) (nhdsWithin 0 (Set.Ioi 0)) (nhds (c ^ θ))
