    First long excursion and first long block: definitions #

    The first jump level of the passage process carrying an excursion of lifetime > 1, its marked excursion, endpoints and stopped cut, the deterministic good-path predicate used for extraction, and their discrete counterparts for scaled skip-free walks (ladder times, first long block, endpoints and cut path).

    Reference: J. Bertoin, Lévy Processes, Cambridge University Press, 1996, Chapter IV.

                structure BGW.StableTrees.GoodLongExtractionPath (M : NNReal) (f : Skorokhod.DLoc) :
                Prop

                Good path for first-long-excursion extraction on the horizon [0, M]. A bundle of geometric facts about f; convergence of the extraction is NOT a field.

                • zero : ↑f 0 = 0
                • passageZero : passageTime 0 f = 0

                  passage at level zero happens at time zero (excludes an initial plateau at the minimum; under the stable law this is (ae_passageTime_eq_firstPassageBelow hθ).2)

                • noNegJumps : NoNegJumps f
                • infContinuous : Continuous (runningInfLoc f)
                • finitePassage (x : NNReal) : firstPassageBelow x f = ↑(passageTime x f)
                • creeping (x : NNReal) : ↑f (passageTime x f) = -↑x
                • strictMono : StrictMono fun (x : NNReal) => passageTime x f
                • regular (x : NNReal) : x ∈ passageJumpSet f → IsRegularExcursionLevel f x
                • noLifetimeOne (x : NNReal) : x ∈ passageJumpSet f → passageTime x f - passageTimeMinus x f ≠ 1
                • hasLongLabel : ∃ (L : NNReal), IsLeast (longLabelSet f) L
                • end_lt : passageTime (firstLongLabel f) f < M
