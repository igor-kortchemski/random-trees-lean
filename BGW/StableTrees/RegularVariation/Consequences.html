    Analytic consequences of regular variation of the normalizing sequence #

    Consequences of regular variation of (a_n) used in the source (lines 1015–1050, 1080–1110, 1136–1251, 1747–1790, 2233–2298), for a monotone a : ℕ → ℝ, positive at n ≥ 1, with RegularlyVaryingSeq ρ a:

    • tendsto_ratio_of_tendsto_div: if k n / n → c > 0 then a (k n) / a n → c ^ ρ (covers a_{⌊εn⌋}/a_n → ε^ρ, a_{n-o(n)}/a_n → 1, a_{n-1}/a_n → 1).
    • eventually_rpow_le_le: a_n = n^{ρ+o(1)}.
    • tendsto_div_self, tendsto_atTop, exists_le_mul, exists_le_mul_of_le_mul: a_n = o(n), a_n → ∞, a_n ≤ C n, and a_y ≤ C a_x whenever y ≤ K x.
    • tendsto_ratio_zero_of_isLittleO: M_n = o(n) gives a_{M_n} / a_n → 0.
    • tendsto_sub_ratio, tendsto_add_ratio, eventually_uniform_sub_add: a_{n ∓ m_n} / a_n → 1 for m_n = o(n), uniformly over m ≤ M_n.
    • tendsto_sqrt_div: for r_n = √(a_{M_n} a_n), r_n / a_{M_n} → ∞ and r_n / a_n → 0.
    • eventually_floor_rpow_bounds, eventually_floor_rpow_div_le, eventually_div_floor_rpow_le: polynomial cutoffs M_n = ⌊n^θ⌋₊.
    • tendsto_mul_div_floor_rpow, tendsto_div_floor_rpow: the two limits in the proof of Lemma lem:critM (source lines 1087–1105), for an n^{o(1)} numerator.
