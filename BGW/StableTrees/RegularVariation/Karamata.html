    Karamata-type sums for regularly varying sequences #

    Source lines 1141–1148 and 1173–1179 (inventory B12): for a monotone sequence a, positive at n ≥ 1, regularly varying of index ρ:

    • RegularlyVaryingSeq.karamata_tail (ρ > 0): ∑_{m < q ≤ N} 1 / (q a_q) ≤ C / a_m for all 1 ≤ m and all N, with one constant C; RegularlyVaryingSeq.summable_inv_mul and RegularlyVaryingSeq.karamata_tail_tsum give summability and the bound for the full tail ∑_{q > m} (a tsum of an indicator).
    • RegularlyVaryingSeq.karamata_sum (0 ≤ ρ < 1): ∑_{h=1}^{n} 1 / a_h ≤ C n / a_n for all n.

    The source invokes "Karamata's theorem". Here the bounds follow from the global Potter bounds (RegularlyVaryingSeq.exists_potter_global) by comparison with the power sums ∑_{q > m} q^{-1-s} ≤ m^{-s}/s and ∑_{h ≤ n} h^{-s} ≤ n^{1-s}/(1-s), which are proved by telescoping.

    Adapted from PoissonDeclumping/RegularVariation/Karamata.lean in igor-kortchemski/rare-subtree-patterns, commit fc5ef722392b1af41e8b9d5fc45d5a521b7823dd (Apache-2.0).

    ∑ q ∈ Finset.Ioc m N, ↑q ^ (-s - 1) ≤ ↑m ^ (-s) / s

    ∑ h ∈ Finset.Icc 1 n, ↑h ^ (-s) ≤ ↑n ^ (1 - s) / (1 - s)

    theorem BGW.StableTrees.RegularlyVaryingSeq.exists_inv_mul_le {ρ : ℝ} {a : ℕ → ℝ} (hrv : RegularlyVaryingSeq ρ a) (hmono : Monotone a) (hpos : ∀ (n : ℕ), 1 ≤ n → 0 < a n) (hρ : 0 < ρ) :
    ∃ (C : ℝ), 0 < C ∧ ∀ (m q : ℕ), 1 ≤ m → m ≤ q → 1 / (↑q * a q) ≤ C * ↑m ^ (ρ / 2) / a m * ↑q ^ (-(ρ / 2) - 1)

    Termwise comparison behind the Karamata tail bound: with s = ρ/2, there is C > 0 with 1 / (q a_q) ≤ (C m^s / a_m) q^(-s-1) for all 1 ≤ m ≤ q.

    ∃ (C : ℝ), 0 < C ∧ ∀ (m N : ℕ), 1 ≤ m → ∑ q ∈ Finset.Ioc m N, 1 / (↑q * a q) ≤ C / a m

    Karamata tail bound (source lines 1141–1148): for ρ > 0 there is C > 0 such that for all m ≥ 1 and all N, ∑_{m < q ≤ N} 1 / (q a_q) ≤ C / a_m.

    Karamata partial-sum bound (source lines 1173–1179): for 0 ≤ ρ < 1 there is C > 0 such that for all n, ∑_{h=1}^{n} 1 / a_h ≤ C n / a_n.
