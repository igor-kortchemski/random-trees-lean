    The binary case of Marchal growth #

    At α = 2, internal positions of a binary tree have weight zero and edge positions have weight one. Edge grafts therefore give Rémy growth.

    source
    theorem BGW.StableTrees.Marchal.selectionWeight_two_binary {n : ℕ} (T : LTree n) (hb : ∀ (v : Fin T.m), T.G.degree v = 1 ∨ T.G.degree v = 3) (p : ↑T.G.edgeSet ⊕ { v : Fin T.m // 3 ≤ T.G.degree v }) :
    selectionWeight T.G 2 p = match p with | Sum.inl val => 1 | Sum.inr val => 0

    At α = 2, on a binary tree every internal vertex has weight zero (d - 1 - α = 0): only edges are selected.

    theorem BGW.StableTrees.Marchal.step_two_binary (k : ℕ) (T : LTree (k + 1)) (hb : ∀ (v : Fin T.m), T.G.degree v = 1 ∨ T.G.degree v = 3) (t : State (k + 2)) :
    (step law_two_support_binary._proof_1 ⋯ k ⟦T⟧) t = ↑{e : ↑T.G.edgeSet | ⟦graft T (Sum.inl e)⟧ = t}.ncard / ↑(2 * k + 1)

    α = 2 step is Rémy's step: from a binary state, graft at a uniformly chosen one of the 2k+1 edges (no plane order is involved: states are non-plane).
