    Uniform bounds for discrete bridge prefix densities #

    The scalar local upper bound and admissible endpoint lower bound, combined with regular variation of the norming, control every prefix strictly before time one.

    source
    noncomputable def BGW.StableTrees.DiscreteBridge.bridgePathDensity (μ : PMF ℕ) (B : ℕ → ℝ) (n : ℕ) (a : NNReal) (x : Skorokhod.D ↑a ℝ) :
    ℝ

    The bridge prefix density as a function of the path on [0,a]: walkProb μ (n-m) (-1-W_m) / walkProb μ n (-1), m = ⌊a n⌋, W_m = B n * x(a) rounded.
