    3. (B3-a) Tail regularly varying of index -2 #

    theorem BGW.StableTrees.Attraction.GaussianBranch.truncSecondMoment_slowlyVarying_of_regVary (ν : MeasureTheory.Measure ℤ) [MeasureTheory.IsProbabilityMeasure ν] (hneg : ν {z : ℤ | z < -1} = 0) (hinf : ¬MeasureTheory.Integrable (fun (z : ℤ) => ↑z ^ 2) ν) (hT : MonotoneDensity.IsRegVaryAtTop (fun (x : ℝ) => ν.real {z : ℤ | x < ↑z}) (-2)) :
    SlowlyVarying (truncSecondMoment ν) ∧ Filter.Tendsto (truncSecondMoment ν) Filter.atTop Filter.atTop

    (B3-a) Let ν be a probability law on ℤ with ν {z < -1} = 0 and infinite second moment. If the right tail T(x) = ν {z > x} is regularly varying of index -2, then the truncated second moment K = truncSecondMoment ν is slowly varying (ratio form K(c x)/K(x) → 1) and unbounded. (The proof does not use T beyond monotonicity and regular variation at the dyadic points: 2 ∫₀ˣ u T = K + x² T - ν{-1} and x² T(x) = o(∫₀ˣ u T).)

    theorem BGW.StableTrees.Attraction.GaussianBranch.gaussQuantile_sq_eventually {ν : MeasureTheory.Measure ℤ} [MeasureTheory.IsProbabilityMeasure ν] (hK : SlowlyVarying (truncSecondMoment ν)) (hKinf : Filter.Tendsto (truncSecondMoment ν) Filter.atTop Filter.atTop) :
    ∀ᶠ (n : ℕ) in Filter.atTop, 0 < gaussQuantile ν n ∧ gaussQuantile ν n ^ 2 = ↑n * truncSecondMoment ν (gaussQuantile ν n)

    (C3-a) If K = truncSecondMoment ν is slowly varying and unbounded, then eventually g_n = gaussQuantile ν n is positive and the crossing is an equality: g_n² = n K(g_n) (K is right continuous, being constant on [k, k+1)).
