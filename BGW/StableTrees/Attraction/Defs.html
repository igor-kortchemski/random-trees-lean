    Scalar stable analysis (M3): definitions and proved bridges #

    Source: arXiv:1110.2163v4, largetrees_final.tex, Section 1 (Proposition 1.7, Definitions 1.8, Theorem 1.10, Lemma 1.11, Remarks 1.9 and 1.12) and Sections 3 and 6 (Lemma 3.4, Theorem 3.5, the Gaussian convolution of Section 6).

    This file contains every definition of milestone M3 and every proved lemma that does not depend on the statements still to be proved (those are in BGW.StableTrees.Attraction, and the proved results that use them are in BGW.StableTrees.Attraction.Consequences). It contains no proof holes.

    The paper's norming constant Γ(1-θ)^{1/θ} and the norming √(n K(z_n)) are not correct as printed; norming is the corrected one (printedConstant_neg, printedNorming_gauss). Ported from BGWLeaves/StableAnalysis/Defs.lean of the author's arXiv:1110.2163v4 formalization (local snapshot of 6 November 2026).

                  3. The printed norming (1.10): the constant and the positive replacement #

                  source

                  Real.Gamma (1 - θ) < 0

                  Γ(1-θ) < 0 for 1 < θ < 2: the base of the printed constant Γ(1-θ)^{1/θ} is negative.

                  source
                  theorem BGW.StableTrees.Attraction.printedConstant_neg {θ : ℝ} (h1 : 1 < θ) (h2 : θ < 2) :
                  Real.Gamma (1 - θ) ^ (1 / θ) < 0

                  The printed real power Γ(1-θ)^{1/θ}, read with Lean's rpow on a negative base, is negative (exp(..)·cos(π/θ) < 0), so the printed formula is not a norming as written. Reading it as |Γ(1-θ)|^{1/θ} gives a positive constant, which is the correct one: the norming is (-Γ(1-θ))^{1/θ} times the tail quantile (negGamma_eq).

                  source
                  theorem BGW.StableTrees.Attraction.negGamma_eq {θ : ℝ} (h1 : 1 < θ) (h2 : θ < 2) :
                  -Real.Gamma (1 - θ) = θ * Real.Gamma (-θ) ∧ -Real.Gamma (1 - θ) = Real.Gamma (2 - θ) / (θ - 1) ∧ 0 < -Real.Gamma (1 - θ)

                  The positive constant: for Laplace exponent u ^ θ (E exp(-u X) = exp(u^θ)) and n P[W > a_n x] → (C x)^{-θ}, the norming constant is C^θ = θ Γ(-θ) = -Γ(1-θ) = Γ(2-θ)/(θ-1) > 0.
