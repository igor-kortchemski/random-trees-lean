    Inversion of a regularly varying integer tail #

    Let ν be a probability measure on ℤ and T(x) = ν.real {z | x < z}. If T is regularly varying of index -θ, θ > 0, then the tail quantile q_n = tailQuantile ν n satisfies q_n → ∞, n T(q_n) → 1; the multiplier quantile q^c_n = inf {x ≥ 0 | T x ≤ c / n} satisfies n T(q^c_n) → c and q^c_n / q_n → c ^ (-1/θ); and q_{⌊λ n⌋} / q_n → λ ^ (1/θ). Ported from BGWLeaves/StableAnalysis/QuantileInversion.lean of the author's arXiv:1110.2163v4 formalization (local snapshot of 6 November 2026).
