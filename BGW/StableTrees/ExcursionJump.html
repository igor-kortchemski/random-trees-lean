    Jumps of the normalized stable excursion #

    At stability index below two, positive jumps of the host inside a valid excursion window give a positive jump of the normalized excursion. The straddling-excursion identity transfers this to the normalized Itô excursion. At index two, the Brownian identification gives a continuous path, whose largest jump is zero.

    0 < Skorokhod.maxJump (excursionRestrict 1 (normalizeExc θ (excursionCut g d f)))

    Deterministic transfer: a positive jump of the host strictly inside a valid cut (g, d) is a positive jump of the normalized cut excursion restricted to [0,1].

    theorem BGW.StableTrees.ae_maxJump_straddling_pos {θ : ℝ} (hθ : 1 < θ ∧ θ ≤ 2) (hθ2 : θ < 2) {t : NNReal} (ht : 0 < t) :
    ∀ᵐ (f : Skorokhod.DLoc) ∂↑(stableLocalLaw θ), 0 < Skorokhod.maxJump (excursionRestrict 1 (normalizeExc θ (straddlingExcursion t f)))

    For 1 < θ < 2, the normalized excursion straddling t > 0 has a positive jump on [0,1], almost surely.
