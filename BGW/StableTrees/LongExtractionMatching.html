    Absence of ladder hits in an interval forces that interval into one consecutive ladder block.

    theorem BGW.StableTrees.ladderTime_zero (ω : ℕ → ℝ) :
    ladderTime ω 0 = 0

    The level-zero ladder time is always zero. Reference: Billingsley (1999), Chapter 3.

    theorem BGW.StableTrees.exists_ladderBlock_spanning {ω : ℕ → ℝ} {n R : ℕ} {a b : ℝ} (ha : 0 < a) (hab : a ≤ b) (hfin : walkHitTime R ω ≠ ⊤) (hR : b < ↑(ladderTime ω R) / ↑n) (havoid : ∀ s ≤ R, ¬(a ≤ ↑(ladderTime ω s) / ↑n ∧ ↑(ladderTime ω s) / ↑n ≤ b)) :
    ∃ r < R, walkHitTime (r + 1) ω ≠ ⊤ ∧ ↑(ladderTime ω r) / ↑n < a ∧ b < ↑(ladderTime ω (r + 1)) / ↑n ∧ ∀ s ≤ R, ↑(ladderTime ω s) / ↑n < a → s ≤ r

    An interval avoiding all ladder hits lies in one finite consecutive ladder block. Reference: Billingsley (1999), Chapter 3.
