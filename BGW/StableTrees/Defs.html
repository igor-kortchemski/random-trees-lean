    Scalar walks and normalized stable attraction #

    The walk has offspring increments K - 1. Its stable-domain hypothesis states scalar weak convergence to a probability law with Laplace transform exp (λ ^ α), for 1 < α ≤ 2. It assumes neither a local limit estimate nor regular variation of the normalizing sequence.

    Extracted from the scalar definitions in PoissonDeclumping/Statements/Defs.lean and PoissonDeclumping/Setup/Walk.lean in igor-kortchemski/rare-subtree-patterns, commit fc5ef722392b1af41e8b9d5fc45d5a521b7823dd (Apache-2.0).

            structure BGW.StableTrees.StableDomain (μ : PMF ℕ) (α : ℝ) (a : ℕ → ℝ) :
            Prop

            Normalized scalar attraction to a spectrally positive stable law with Laplace exponent λ ^ α. The limit law is an existence hypothesis here. The normalizer is nondecreasing and positive for n ≥ 1.

            • critical : IsCritical μ
            • nondegenerate : μ 1 ≠ 1
            • alpha_mem : 1 < α ∧ α ≤ 2
            • monotone : Monotone a
            • pos (n : ℕ) : 1 ≤ n → 0 < a n
            • converges : ∃ (ν : MeasureTheory.Measure ℝ), MeasureTheory.IsProbabilityMeasure ν ∧ (∀ (lam : ℝ), 0 < lam → ∫ (y : ℝ), Real.exp (-lam * y) ∂ν = Real.exp (lam ^ α)) ∧ ∀ (f : BoundedContinuousFunction ℝ ℝ), Filter.Tendsto (fun (n : ℕ) => ∫ (x : ℝ), f x ∂MeasureTheory.Measure.map (fun (z : ℤ) => ↑z / a n) (walkLaw μ n)) Filter.atTop (nhds (∫ (x : ℝ), f x ∂ν))
