    The closed stable bridge #

    This module characterizes the closed stable bridge by its strict prefix laws and terminal pinning, proves invariance under time reversal, and establishes absence of discontinuities at fixed times (P. Fitzsimmons, J. Pitman and M. Yor, Markovian bridges: construction, Palm interpretation, and splicing, Seminar on Stochastic Processes 1992, Birkhäuser, 1993; L. Chaumont, Excursion normalisée, méandre et pont pour les processus de Lévy stables, Bull. Sci. Math. 121 (1997), 377–403).

    theorem BGW.StableTrees.integral_restrict_stableBridgeLaw {θ a : ℝ} (hθ : 1 < θ ∧ θ ≤ 2) (ha : 0 < a) (ha1 : a < 1) {F : Skorokhod.D a ℝ → ℝ} (hF : Measurable F) (hFb : ∃ (C : ℝ), ∀ (x : Skorokhod.D a ℝ), |F x| ≤ C) :
    ∫ (f : Skorokhod.D 1 ℝ), F (Skorokhod.restrict ⋯ f) ∂↑(stableBridgeLaw θ) = ∫ (g : Skorokhod.D a ℝ), bridgePrefixWeight θ a ⋯ g * F g ∂↑(stableProcessLaw θ a)

    Prefix expectation. For 0 < a < 1 and bounded Borel F on D a ℝ: E_bridge[F(f|[0,a])] = E_{P_a}[w_a · F]. The integrand on the right lives on D a ℝ (it is not another restriction from D 1 ℝ).

    theorem BGW.StableTrees.stableBridgeLaw_unique {θ : ℝ} (hθ : 1 < θ ∧ θ ≤ 2) {Q : MeasureTheory.ProbabilityMeasure (Skorokhod.D 1 ℝ)} (hprefix : ∀ (a : ℝ) (ha : 0 < a) (ha1 : a < 1), MeasureTheory.Measure.map (Skorokhod.restrict ⋯) ↑Q = bridgePrefixLaw θ a ⋯ ↑(stableProcessLaw θ a)) (hend : ∀ᵐ (f : Skorokhod.D 1 ℝ) ∂↑Q, f ⟨1, ⋯⟩ = Function.leftLim ⇑f ⟨1, ⋯⟩) :
    Q = stableBridgeLaw θ

    Uniqueness, minimal endpoint form. A law on D 1 ℝ with the prescribed prefix laws on every [0, a], a < 1, and which a.s. has no jump at time 1 (f 1 = f 1-), is the stable bridge. (The prefix laws force f 1- = 0 a.s.)

    theorem BGW.StableTrees.exists_ne_stableBridgeLaw_same_prefixes {θ : ℝ} (hθ : 1 < θ ∧ θ ≤ 2) :
    ∃ (Q : MeasureTheory.ProbabilityMeasure (Skorokhod.D 1 ℝ)), Q ≠ stableBridgeLaw θ ∧ ∀ (a : ℝ) (ha : 0 < a) (ha1 : a < 1), MeasureTheory.Measure.map (Skorokhod.restrict ⋯) ↑Q = bridgePrefixLaw θ a ⋯ ↑(stableProcessLaw θ a)

    Prefix laws alone do not determine the law: the value at time 1 is free. This is the necessity of the endpoint hypothesis (a concrete second law with the same prefixes: the bridge with its terminal value overwritten by 1).

    ∀ᵐ (f : Skorokhod.D 1 ℝ) ∂↑(stableBridgeLaw θ), (Skorokhod.reverseBridge f) ⟨0, ⋯⟩ = 0 ∧ (Skorokhod.reverseBridge f) ⟨1, ⋯⟩ = 0 ∧ Function.leftLim ⇑(Skorokhod.reverseBridge f) ⟨1, ⋯⟩ = 0

    The reversed bridge is again a pinned bridge: almost surely it starts and ends at 0 and has no left jump at 1.
