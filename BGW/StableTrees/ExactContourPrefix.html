    Contour bracketing using only a strict height prefix #

    A height bound at the right endpoint excludes bracket indices beyond that endpoint. The resulting comparison uses heights and their oscillations only on the larger prefix.

    source
    theorem BGW.PlaneTree.heightSeq_add_le (t : PlaneTree) (m d : ℕ) :
    t.heightSeq (m + d) ≤ t.heightSeq m + d

    Along the DFS order, the height can increase by at most the number of steps.

    ∃ i < t.size, i ≤ m ∧ u - 1 ≤ ↑i ∧ ↑i ≤ u + ↑(t.heightSeq i) / 2 ∧ |t.contourLin (2 * u) - ↑(t.heightSeq i)| ≤ |↑(t.heightSeq (i + 1)) - ↑(t.heightSeq i)| + 1
