    Pathwise passage intervals #

    Order and window-infimum facts for the passage process. These facts precede the use of uniqueness of the minimum on rational windows in the excursion-support argument (J. Bertoin, Lévy Processes, Cambridge University Press, 1996, Chapter VII).

    def BGW.StableTrees.passageJumpSet (f : Skorokhod.DLoc) :

    The set of positive jump levels of the passage process: {x > 0 | T_{x-} < T_x}.
