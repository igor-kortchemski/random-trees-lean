    Joint extrema under fixed-horizon reversal #

    Reference: J. Bertoin, Lévy Processes, Cambridge University Press, 1996, Chapters IV and VI.

    theorem BGW.StableTrees.iSup_reverseIncrements {T : ℝ} (hT : 0 ≤ T) (f : Skorokhod.D T ℝ) (hf : ∀ (t : ↑(Set.Icc 0 T)), Function.leftLim (⇑f) t ≤ f t) :

    Reversal turns the supremum into the terminal value minus the running infimum, for a path whose jumps are nonnegative.
