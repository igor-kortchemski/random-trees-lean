    Exact-size walk and height prefix laws #

    Both coordinates come from one tree, with the sealed terminal walk convention. The restriction and marginal identities identify the law with the existing walk-prefix API.

    source
    noncomputable def BGW.StableTrees.ExactPair.exactPairLaw (μ : PMF ℕ) (B : ℕ → ℝ) (n : ℕ) (_hn : Admissible μ n) (a : NNReal) :
    MeasureTheory.ProbabilityMeasure (Skorokhod.D ↑a ℝ × C(↑(Set.Icc 0 ↑a), ℝ))

    The exact-size pair law on [0,a]: the (walk, height) pair of ONE BGW tree conditioned on size exactly n (sealed K02 exactTreeLaw, totalized), at scales nt, 1/B n, B n / n.
