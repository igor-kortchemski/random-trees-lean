    Grafting a leaf on a finite tree #

    The graph operation either adds a leaf at an existing branch vertex or subdivides an edge and attaches the new leaf to the subdivision vertex.

    source
    noncomputable def BGW.StableTrees.Marchal.graftGraph {m : ℕ} (G : SimpleGraph (Fin m)) (p : ↑G.edgeSet ⊕ { v : Fin m // 3 ≤ G.degree v }) :
    SimpleGraph (Fin (match p with | Sum.inl val => m + 2 | Sum.inr val => m + 1))

    Graft a new leaf A_{n+1} (the last vertex) on the middle of an edge (new midpoint m, new leaf m+1) or on an internal vertex (new leaf m).
