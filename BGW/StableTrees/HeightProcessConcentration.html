    Ancestral concentration of the exploration measure #

    The Stieltjes measure is carried by ancestral times: outside that set the future infimum is locally constant. The fixed-horizon clock identity then bounds the heights seen by that measure. Fixed-time positivity also identifies the zero-height event.

    source
    theorem BGW.StableTrees.ae_exploration_ancestral_times (f : Skorokhod.DLoc) (hf : ∀ (r : NNReal), Function.leftLim (↑f) r ≤ ↑f r) (t : NNReal) :
    ∀ᵐ (s : ℝ) ∂(explorationStieltjes f t).measure.restrict (Set.Ioc 0 ↑t), Function.leftLim (↑f) s.toNNReal ≤ futureInf f t s.toNNReal

    The exploration Stieltjes measure is carried by ancestral times, including endpoint atoms.

    ∀ᵐ (f : Skorokhod.DLoc) ∂↑(stableLocalLaw θ), ∀ᵐ (s : ℝ) ∂(explorationStieltjes f t).measure.restrict (Set.Ioc 0 ↑t), 0 ≤ height θ f s.toNNReal ∧ height θ f s.toNNReal ≤ height θ f t ∧ heightRaw θ f s.toNNReal = ENNReal.ofReal (height θ f s.toNNReal)

    At a fixed horizon, the Stieltjes measure sees finite ancestral heights below the endpoint.
