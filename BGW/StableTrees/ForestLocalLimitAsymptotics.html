    Tree-tail asymptotics and the tail-to-exact ratio #

    The lattice mass asymptotic is summed with the exact residue-class Karamata constant. The resulting tree-tail asymptotic holds along all integers.

    Reference: J.-F. Le Gall, Random trees and applications, Probab. Surveys 2 (2005), Section 1.

    source
    theorem BGW.StableTrees.treeTail_asymp {μ : PMF ℕ} {θ : ℝ} {B : ℕ → ℝ} (h : StableDomain μ θ B) :
    Filter.Tendsto (fun (n : ℕ) => B n * forestTail μ 1 n) Filter.atTop (nhds (θ * Scalar.stableDensity θ 0))

    Tree tail asymptotics along ALL n: B_n G_1(n) → θ p₁(0). No admissibility needed.
