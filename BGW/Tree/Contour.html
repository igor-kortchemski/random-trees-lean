    The discrete contour of a finite plane tree #

    The contour records heights during the complete depth-first traversal, starting and ending at the root. Each child contributes its own contour raised by one, followed by a return to height zero. The root-only tree has contour [0]; a tree with n vertices has contour length 2 * (n - 1) + 1, hence traversal duration 2 * (n - 1). Vertex addresses and their lengths identify exactly the heights encountered. This is a list of discrete heights, without any continuous interpolation.
