    Discrete height and ancestral minima of the Łukasiewicz path #

    Height is the length of a valid DFS vertex address, with the root at index zero. The path is the integer sum of increments strictly before its time index. The finite-height domain excludes the terminal path time. A fringe occupies one contiguous address block, and its path first falls below its starting value at the end of that block.

    These are the discrete conventions used in Le Gall, Random trees and applications, Proposition 1.2, and in the height/Łukasiewicz definitions of Kortchemski, A simple proof of Duquesne's theorem on contour processes of conditioned Galton–Watson trees, Section 1.1 (local source lines 424–445).
