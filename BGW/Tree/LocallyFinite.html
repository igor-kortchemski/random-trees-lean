    Finite trees in canonical offspring coordinates #

    The existing PlaneTree uses zero-based child indices. The locally finite carrier uses positive indices to match the existing BGW-law construction. positiveAddress is the explicit conversion; zero is always an invalid index on the locally finite side. All finite-tree reasoning uses the public list API.
