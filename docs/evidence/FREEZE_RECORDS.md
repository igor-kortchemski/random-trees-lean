# Freeze records

Each sealed node of the 2026 campaigns has a freeze record: a JSON file written by `freeze_check.py`
(from the `lean-autoformalization-skills` package) that hashes, printed in full with `pp.all`, the
type of every frozen declaration and, transitively, the types and values of the project definitions
it relies on. Format 3 (skills v1.9.0 to v1.10.0) does not freeze the Lake configuration or the
dependency `.olean` files; format 4 (skills v2.0.0) does. The records are kept outside the
repository, where proof workers could not write. The table authenticates a separately obtained
copy of each record. Repeating the campaign freeze checks requires those JSON files and the
v2.0.0 checker used to generate them. Readers can repeat the public build and axiom audit with
`python3 scripts/check.py` from the repository root.
